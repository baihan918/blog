01 · 先看对象

一个 Token，在模型里就是一张“数字特征卡”

词只是人类看到的形式；进入模型后，每个 Token 都会变成一个 hidden vector。

喜欢
1.2
-0.4
2.8
0.7
-1.1
3.4
← LayerNorm 沿着这一整排 hidden features 计算 →
别把每一维硬翻译成人类概念：真实模型可能有 768、4096 甚至更多维。某一维通常不是单独的“情感”或“词性”，而是许多信息混合形成的内部坐标。

“同一个 Token 的所有特征”是什么意思？

就是只拿“喜欢”自己的这一整排数字计算均值和方差，不把“我”“学习”或别的句子混进来。

[batch, sequence, hidden] → 对每个 [hidden] 单独归一化

一句话先记住

LayerNorm 不是理解这些数字的语义，而是在每道工序前，先把它们使用的“数值尺子”校准好。

把“隐藏向量”和“隐藏维度”说准确

一个 Token 对应一个隐藏向量；隐藏维度 D 是多少，这个向量里就有多少个数。不是一个 Token 拥有 D 个向量，而是它拥有一个由 D 个特征值组成的向量。

一个 Token → 一个隐藏向量 h = [h₁, h₂, h₃, …, hᴅ]
D = 4“喜欢” → [2.4, 0.6, 4.2, 1.8]，LayerNorm 就在这 4 个数之间计算。
D = 4096真实大模型中，一个 Token 的隐藏向量可能包含 4096 个特征值。
统计范围每个 Token 独立得到自己的均值 μ 和方差 σ²，其他 Token 不参与。
像一张体检表：一个人只有一张表，但表里有身高、体重、血压等许多栏目。LayerNorm 校准的是当前这个人整张表里的数值，不是把全班同一栏拿来比较。
这里的“单个 Token”不等于只有原始词义：经过 Attention 后，这一个 Token 的隐藏向量已经可能融合了整段上下文的信息；LayerNorm 仍然只在它自己的 D 个特征值上计算。
02 · 核心类比

归一化，就像统一照片的亮度和对比度

照片内容可能相同，但拍摄时有的太亮、有的太暗，有的对比强、有的灰蒙蒙。数值也有类似问题。

先看同一幅山景的三种状态

整体太暗均值偏低：整张图像左移
对比度太弱标准差偏小：明暗挤在一起
校准之后中心和波动范围都更稳定
类比对应：均值像整体亮度；标准差像对比度刻度。LayerNorm 先去掉整体亮暗，再统一对比度大小。

不是“算出均值和方差”就归一化了，而是用它们完成三步

1均值：找到中心先看看整组数字总体偏高还是偏低，相当于找到照片的平均亮度。
2减均值：搬到同一起点把中心搬到 0，去掉“整组一起加了多少”的影响。
3除标准差：换成同一把尺子把波动幅度调到相同尺度，去掉“整组一起放大了多少”的影响。
原数值 → 减去自己的中心 → 除以自己的典型波动 → 稳定尺度

减均值，去掉整体偏移

[10, 20, 30] 和 [110, 120, 130] 内部形状相同，后一组只是整体加了 100。

各自减去均值后都会变成：

[-10, 0, 10]

除标准差，去掉整体缩放

[-10, 0, 10] 和 [-20, 0, 20] 形状相同，后一组只是波动放大两倍。

各自除以自己的标准差后都会接近：

[-1.225, 0, 1.225]
03 · 关键追问

方差负责“算离散”，标准差才是“原刻度”

这两个词常被混着说。最准确的分工是：方差是计算工具，标准差是还原后的典型距离。

为什么不能直接平均“离中心的距离”？

数字 [10, 20, 30] 的中心是 20，偏差是 [-10, 0, 10]。直接平均会得到 0，因为左右两边互相抵消了，但数据明明有波动。

中心左边是负，右边是正先平方，避免正负抵消
原偏差
平方距离

把偏差平方后再平均，得到的就是方差：它描述“平均平方距离有多大”。

方差为什么不是最终的“尺子”？

如果原数据单位是厘米，平方后的方差单位就是平方厘米。它能衡量离散，但已经不是原来的长度刻度。

原数据厘米 cm
方差平方厘米 cm²
标准差开方后回到 cm

标准差是什么？

标准差就是给方差开平方，把“平方后的波动”还原成与原数据同单位的典型距离。

面积与边长：方差像 100 m² 的面积；标准差像开平方后得到的 10 m 边长。要衡量原来的长度，应该使用边长。

为什么 LayerNorm 除以标准差，而不是方差？

[1, 2, 3]标准差约 0.816
方差约 0.667
×10 →
[10, 20, 30]标准差也 ×10
方差却 ×100

数据整体放大 10 倍，我们需要除以一个也放大 10 倍的量，才能刚好抵消。因此应该除以标准差；若除以放大 100 倍的方差，就会缩过头。

数据 ×10 ÷ 标准差 ×10 → 抵消　｜　数据 ×10 ÷ 方差 ×100 → 过度缩小
纠正一句容易混淆的话：不是“方差就是刻度”。准确说法是：方差通过平均平方距离衡量离散程度；标准差才把这种离散程度表示回原数据的刻度。
04 · 两种归一化

LayerNorm 看一张特征卡，BatchNorm 看一摞同类卡

两者不是谁更高级，而是横向统计的方向不同，适合的任务也不同。

Layer Normalization

对当前 Token 自己的全部 hidden features 计算均值和方差。

像什么：每个人拿自己的整张体检表，校准这张表内部各项指标的数值尺度。

Batch Normalization

固定某一个特征，跨 batch 中的多个样本计算均值和方差。

像什么：拿全班同学的“身高”这一栏放在一起，判断每个人相对全班的位置。
比较点LayerNormBatchNorm
统计谁一个 Token 内部的所有特征同一特征跨多个样本
依赖 batch 吗不依赖，batch size = 1 也能用依赖，batch 太小时统计不稳定
训练与推理都用当前 Token 自己的统计量训练用当前 batch，推理通常用累计统计量
更自然的场景Transformer、变长序列、自回归生成CNN 等同一通道语义较稳定的场景
05 · 回到模型

Transformer 为什么更偏爱 LayerNorm？

因为句子长短、batch 大小和生成阶段都在变化，而每个 Token 自己的特征维度是稳定的。

校准依据：当前最新的残差累积状态

你的理解可以写成一条不断循环的流水线：每次子层都读取当前最新状态，先校准，再计算本轮变更量，最后把变更加回残差主干。

1当前状态 x它已经包含前面多层、Attention 和 FFN 累积下来的历史变更。
2LN(x) → 子层 → Δx基于最新状态制作一个校准后的“工作副本”，用来计算本轮变更。
3x + Δx → 新状态 x′把本轮变更加回残差主干；下一次 LayerNorm 就以 x′ 为依据。
x → LN(x) → Attention → Δx₁ → x₁ = x + Δx₁ → LN(x₁) → FFN → Δx₂ → x₂ = x₁ + Δx₂
Pre-LN 的关键细节：LayerNorm 不直接改写残差主干 x，而是把 LN(x) 交给 Attention 或 FFN。残差主干继续保存原状态与历次变更；下一个 LayerNorm 再读取更新后的主干。

不依赖旁边坐着谁

一个 batch 放 1 句话还是 128 句话，都不会改变当前 Token 的归一化方式，分布式训练和梯度累积也更自然。

适合变长序列

句子有长有短，还会出现 padding。LayerNorm 不需要把不同位置、不同句子的 Token 混在一起统计。

适合逐 Token 生成

大模型常常一次只生成一个新 Token，batch 和上下文长度不断变化。LayerNorm 仍然可以独立、稳定地工作。

训练与推理规则一致

LayerNorm 两个阶段都根据当前 Token 自己计算，不需要维护一套训练期的滑动均值和方差。

它稳定的是数值平台，不是判断语义对错

LayerNorm 能避免某层输入忽大忽小，让 Attention 和 FFN 更容易训练；但它不会判断“这个 Token 理解得对不对”。

工厂类比：它像每道工序前校准尺子和亮度计。工具刻度稳定了，工人更容易施工，但校准仪器并不替工人决定产品应该做成什么。

类比理解之后，再看完整公式与摆放位置

ε 是一个很小的安全垫，防止所有特征恰好相同时除以 0；γ 和 β 是模型学习的缩放与偏移，让归一化之后仍能恢复任务需要的表达尺度。

y = γ · (x − μ) / √(σ² + ε) + β
Pre-LN（现代模型常见）x + Attention(LN(x))：先校准，再进入子层，深层梯度通常更稳定。
Post-LN（原始 Transformer）LN(x + Attention(x))：先计算与残差相加，再做校准。
RMSNorm现代模型中的常见替代方案；保留尺度校准思想，但不减均值。

最后把整段对话压缩成四句话

均值找到整组数字的中心在哪里，像照片的整体亮度。
方差用平均平方距离计算数据有多分散，避免正负偏差抵消。
标准差给方差开平方，回到原数据的单位，成为真正可用的波动刻度。
LayerNorm每个 Token 独立减去自己的均值、除以自己的标准差，再学习缩放 γ 和偏移 β。
中心归零 + 刻度统一 + 可学习恢复 = 稳定但仍有表达力
06 · 现代大模型取舍

LLaMA 用 RMSNorm，LayerNorm 仍然有必要吗？

有必要。RMSNorm 不是推翻 LayerNorm，而是保留其中最关键的尺度校准，省略中心校准。

LLaMA 实际怎么做？

LLaMA 系列使用 RMSNorm，并采用 Pre-Norm 结构：Attention 前校准一次，得到最新残差状态后，在 FFN 前再校准一次。

h = x + Attention(RMSNorm(x))
out = h + FFN(RMSNorm(h))

它的统计范围没有改变：仍然针对当前单个 Token 的 D 维隐藏向量独立计算，不跨 Token、不依赖 batch。

官方实现：Llama 2 · Llama 3 · Llama 4

LayerNorm：完整校准

先减去均值，把中心移到 0；再除以标准差，统一波动尺度。

中心校准 + 尺度校准
照片类比：同时调整整体亮度和对比度。

RMSNorm：只校准尺度

不减均值，直接根据所有特征值的均方根 RMS 控制整体数值幅度。

x / √(mean(x²) + ε) · γ
照片类比：不把亮度中心搬到 0，只控制画面整体能量不要忽强忽弱。

为什么很多大模型只校准尺度也够用？

深层残差网络最直接的训练风险之一，是隐藏向量的整体幅度经过多层后越来越大或越来越小。实践中，RMSNorm 只控制幅度就能提供足够好的稳定性，同时省去减均值步骤，计算更简洁。

“足够”不是数学上永远等价：RMSNorm 不会像 LayerNorm 那样消除整体平移。例如两组内部形状相同、但整体都加了 100 的向量，LayerNorm 会消除这个偏移，RMSNorm 不会完全消除。

LayerNorm 为什么没有过时？

它仍是一种完整、通用的归一化方法。当架构需要同时控制中心与尺度，或者原模型就是围绕 LayerNorm 训练时，它仍然是正确选择。

不能直接互换

训练好的后续权重已经适应原来的归一化输出。直接把 LayerNorm 换成 RMSNorm，或反过来，都会改变中间分布，通常需要重新训练或专门适配。

实际选择：跟随架构，再用实验验证

场景更合理的做法
学习归一化原理先理解 LayerNorm 的“减均值 + 除标准差”，再把 RMSNorm 理解成只保留尺度校准的简化方案。
复现已有模型严格跟随原架构：LLaMA 用 RMSNorm，采用 LayerNorm 的模型继续使用 LayerNorm。
设计新的 Decoder-only LLMRMSNorm 是常见起点，但是否更好仍应由训练稳定性、效果和性能实验决定。
最终类比：LayerNorm 是“亮度 + 对比度”的完整校准；RMSNorm 是只保留最关键的强度校准。后者更轻，不代表前者没用。
