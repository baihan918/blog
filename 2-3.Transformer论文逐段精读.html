01 · The big idea

论文到底解决了什么？

在 2017 年之前，机器翻译主流方案通常依赖 RNN/LSTM，一步一步读句子。论文提出：序列内部的依赖关系，可以主要靠 Attention 建模，不必靠循环传递隐藏状态。

01摆脱串行阅读RNN 像接力传话，后一个位置要等前一个；Transformer 训练时能同时处理各位置。
02缩短信息路径相隔很远的两个词，在一层自注意力中就能直接建立联系，不必层层传递。
03更好利用硬件核心是矩阵乘法，特别适合 GPU/TPU 并行，训练吞吐量明显提高。
🍎 通俗比喻：RNN 像全班排成一列传纸条，最后一个同学想知道第一句话，要等纸条一路传来；Self-Attention 像大家同时打开共享文档，每个人都能直接看全句，并圈出自己最该关注的位置。

03 · Paragraph by paragraph

论文逐段精读

下面按原论文从摘要到结论的逻辑展开。每段固定回答三个问题：原文讲什么、怎么通俗理解、面试怎么概括。

P1

摘要：只靠 Attention，也能做序列转换

论文主张
📄 论文在说

提出 Transformer：完全基于 Attention 的序列转换架构；在 WMT 2014 英德、英法翻译上取得强结果，同时训练成本更低。

🍭 通俗翻译

以前翻译像边听边记的同传；现在先让所有词彼此“开会”，再决定怎样翻译。会议能并行开，因此训练更快。

🎤 面试表达

Transformer 的关键创新不是发明 Attention，而是把它提升为主要计算骨架，替代循环和卷积来建模依赖。

校正一下：学习 PDF 第 15 页“也不需要编码器和解码器”的说法不准确。原始 Transformer 明确包含 Encoder 和 Decoder；它不再依赖的是 RNN / CNN。
P2

引言与背景：RNN 为什么成了瓶颈？

问题来源
📄 论文在说

RNN 的隐藏状态按时间步顺序计算，阻碍训练样本内部的并行；长序列还会受到内存和信息传递路径的限制。

🍭 通俗翻译

像盖章流水线：第 20 个词必须等前 19 个词办完手续。哪怕有很多 GPU，也很难把同一句话真正拆开同时做。

🎤 面试表达

Transformer 通过全序列矩阵运算提高训练并行度，并把任意两位置之间的最短路径压到常数级。

P3

模型架构：层层精修，而不是每层重新做

Encoder / Decoder
📄 论文在说

Encoder 和 Decoder 都由 N=6 个相同结构的层堆叠。Encoder 每层含 Self-Attention 与 FFN；Decoder 还多出 Masked Attention 和 Cross-Attention。

🍭 通俗翻译

像 1:1 还原一个立方体灯箱：第一轮搭骨架，后面每轮都基于现有成品修正比例、材质和光影，而不是推倒重来。

🎤 面试表达

多层与多头不是一回事：多头在同一层并行看不同关系；多层是串行迭代，让表示逐步抽象和精炼。

P4

Scaled Dot-Product Attention：先匹配，再取内容

核心公式
📄 论文在说

用 Q 与 K 的点积得到相关性分数，除以 √dₖ 后做 Softmax，最后用权重对 V 加权求和。

🍭 通俗翻译

Q 是搜索请求，K 是每条资料的索引标签，V 是资料正文。先用请求匹配索引，再按匹配程度取回正文。

🎤 面试表达

QKᵀ 决定“看谁”，Softmax 把分数变成分配比例，乘 V 决定“拿回哪些信息”。

P5

Multi-Head Attention：同一句话，同时派多个观察员

表示子空间
📄 论文在说

将 Q、K、V 经过多组可学习投影，在较低维的不同子空间中并行执行 Attention，再拼接并投影回 d_model。

🍭 通俗翻译

一个观察员盯语法，一个盯指代，一个盯情绪，一个盯远距离关系。最后把各自的会议纪要合并。

🎤 面试表达

多头提升的是表示能力：允许模型在同一层、同一位置上同时关注不同关系，而不是简单重复计算。

P6

Attention 的三种用法：自省、回看、查资料

三条信息流
📄 论文在说

Encoder Self-Attention 的 Q/K/V 都来自输入；Decoder Masked Self-Attention 来自已生成目标；Cross-Attention 的 Q 来自 Decoder，K/V 来自 Encoder。

🍭 通俗翻译

阅读团队内部讨论＝Encoder 自注意力；写作团队回看已写内容＝Masked 自注意力；写作团队查阅读笔记＝交叉注意力。

🎤 面试表达

区分三种 Attention，关键看 Q、K、V 的来源以及是否带因果遮罩。

P7

FFN、残差和 LayerNorm：想清楚，还要加工稳定

层内加工
📄 论文在说

每个位置独立通过相同的两层前馈网络；每个子层外使用残差连接并做 LayerNorm，即原论文的 LN(x + Sublayer(x))。

🍭 通俗翻译

Attention 负责收集资料，FFN 负责每个位置独立消化；残差保留旧稿，LayerNorm 把每次加工后的“音量”调回稳定范围。

🎤 面试表达

残差改善深层网络的信息与梯度通路，归一化稳定数值尺度，FFN 提供非线性与逐位置特征变换。

版本差异：2017 原论文采用 Post-LN；现代大模型常用 Pre-LN，即 x + Sublayer(LN(x))，训练更深网络通常更稳定，并常把 LayerNorm 换成 RMSNorm。
P8

Embedding 与位置编码：词是谁，还要知道坐哪儿

顺序信息
📄 论文在说

Token Embedding 乘 √d_model 后与正弦/余弦位置编码相加；不同频率让模型获得位置与相对位移线索。

🍭 通俗翻译

“苹果”是选手姓名，位置编码是座位号。没有座位号，“狗咬人”和“人咬狗”只剩同一袋词。

🎤 面试表达

自注意力本身对排列不敏感，因此必须注入顺序。正弦位置编码无需学习，并可计算到训练长度以外的位置。

校正一下：Embedding 乘 √d_model 不是为了“防止数值太大”，而是提高词向量的尺度，使其与相加的位置编码处在更合适的量级。现代模型还常用 RoPE、ALiBi 等方案。
P9

为什么 Self-Attention：三项指标的权衡

复杂度分析
📄 论文在说

论文比较每层计算复杂度、可并行操作数和远距离位置间的路径长度。Self-Attention 并行度高，任意两位置路径长度为 O(1)。

🍭 通俗翻译

不仅比较“算多少”，还比较“能否同时算”和“消息要转几手”。Attention 的信息不用经过中间人。

🎤 面试表达

Self-Attention 用 O(n²) 代价换来全局直接交互和训练并行；当序列很长时，平方复杂度会成为主要瓶颈。

P10

训练、结果、泛化与结论

证据闭环
📄 论文在说

在 WMT 翻译任务训练，使用 Adam、warmup、dropout、label smoothing；消融实验验证模型尺寸、头数、位置编码等设计，并在英语成分句法分析上泛化。

🍭 通俗翻译

不只说“新车更快”，还要同赛道计时、拆掉零件重测，再换一个赛道看看是不是只会刷题。

🎤 面试表达

论文的贡献由三类证据支撑：翻译指标与训练成本、组件消融、跨任务泛化。结论是 Attention 可成为序列建模主骨架。

04 · Attention under the hood

把一行公式拆成五个动作

Attention 不是“凭感觉关注”，而是一套可微分的信息检索流程。

Attention(Q, K, V) = softmax((QKᵀ + mask) / √dₖ) V
① QKᵀ逐个比较
匹配程度
② ÷ √dₖ压住过大的
点积分数
③ + mask禁看 padding
或未来答案
④ softmax变成总和为 1
的注意力比例
⑤ × V按比例汇总
真正的信息
Q

Query：我现在想找什么

由当前词的表示通过 WQ 投影得到。它不是一句人工写死的问题，而是一组随上下文和训练学到的数值特征。

例：“它”的 Q 可能编码“我需要确认当前指代对象”等检索方向。
K

Key：我能用什么被找到

每个词通过 WK 生成自己的“检索标签”。Q 与哪个 K 更匹配，那个位置就更值得关注。

例：“苹果”的 K 可能包含名词、可指代实体、单数等线索。
V

Value：找到我后带走什么

V 不是“苹果”这两个字，而是苹果当前隐藏状态经 WV 投影后的向量，包含语义、句法、上下文等可传递信息。

“苹果很红，我吃了它”里，“苹果”的 V 可能融合物体、食物、红色、被吃等上下文特征。

为什么 Q、K 算匹配时不用 V？

因为检索被拆成两步：先决定去哪找，再取回找到的内容。Q/K 专心生成地址和相关性，V 专心承载信息。如果匹配阶段就把 V 混进去，定位与内容的职责会纠缠，模型更难学习稳定的检索规则。

“它”的 Q 会直接包含“红色”吗？

不一定，更不能理解成文字列表。若“红色”在“它”后面，单向 Decoder 的“它”看不到未来；双向 Encoder 可以看整句。Q 是当前层算出的向量，是否带有“红色相关线索”取决于架构、遮罩和前层上下文。

为什么除以 √dₖ？

dₖ 越大，随机点积的方差通常也越大；分数过大会让 Softmax 接近“一刀切”，梯度变小。除以 √dₖ 相当于给相似度降温，让训练早期仍有可比较、可学习的概率分布。

Softmax 到底做了什么？

把任意实数分数变成非负、总和为 1 的权重。它会放大相对差异：高分位置分到更多“信息预算”，但最终输出仍是 V 的加权混合，不是简单挑出一个词。

Q、K 为什么用不同矩阵？

“我想找什么”和“我如何被找到”是两个角色，分开投影更灵活，也允许非对称关系。即使 WQ=WK，也不等于只能关注自己；跨词点积仍然存在，只是表达能力受限。

点积为何比加性 Attention 常用？

点积能直接化为高效矩阵乘法，GPU 上速度和内存访问更友好。加性 Attention 其实是用一个小 MLP 学兼容度，不是把两个向量直接相加；两者表达都有效，工程效率让缩放点积更流行。

05 · The supporting cast

核心模块各自解决什么？

把 Transformer 想成一个团队：Attention 负责沟通，但没有下面这些同事，系统仍然无法稳定地学、记住顺序或生成正确答案。

🧭 位置编码

给每个词加入“座位号”，让排列敏感。没有它，纯 Self-Attention 无法仅凭结构区分“猫追狗”和“狗追猫”的顺序。

原论文：固定正弦/余弦；现代常见：RoPE、ALiBi、可学习绝对位置。

🪜 残差连接

每个子层只学习“在原表示上改多少”，输出是旧稿加修改量。它提供信息与梯度的直通路径，使深层网络更容易训练。

会跳过层吗？数学上确实存在直通分支，但不是硬性把某层关掉；子层输出仍会参与相加，模型可学到“少改或多改”。

📏 LayerNorm

对每个 token 自己的特征维度做归一化，再用可学习参数缩放和平移。它像每轮调整后重新校准尺子，使不同样本、不同位置的数值尺度更稳定。

原论文 Post-LN：LN(x + Sublayer(x))。
现代 Pre-LN：x + Sublayer(LN(x))。

🍳 FFN

Attention 把别处信息搬到当前位置，FFN 再对每个位置独立地非线性加工。相同参数应用于所有位置，但不同 token 得到不同输出。

原论文：Linear → ReLU → Linear。现代 LLM 常用 GELU、SiLU、SwiGLU。

🙈 Mask

Padding Mask 不让模型关注补齐符号；Causal Mask 不让 Decoder 偷看未来词。实现时通常把禁看位置加上负无穷，Softmax 后权重变成 0。

训练可并行：整段目标能同时计算，只是每个位置被遮住未来；推理仍串行：下一个 token 要等上一个生成。

🏗️ 多层堆叠

一层完成一次“交流＋加工”，多层让信息反复重组：从字词关系，到短语结构，再到语义、指代与任务意图。

与多头区别：多头是同一轮的多视角并行；多层是多轮串行精修。一个增加同层宽度，一个增加推理深度。

07 · From paper to PyTorch

代码实现：沿着张量形状走

学习 PDF 用约五页代码依次实现 Self-Attention、位置编码、Encoder、Decoder 和完整 Transformer。最重要的不是背代码，而是每一步都知道张量在表达什么。

scaled_dot_product_attention.py
# x: [batch, seq_len, d_model]
Q = W_q(x).view(B, L, heads, head_dim).transpose(1, 2)
K = W_k(x).view(B, L, heads, head_dim).transpose(1, 2)
V = W_v(x).view(B, L, heads, head_dim).transpose(1, 2)

scores = Q @ K.transpose(-2, -1) / math.sqrt(head_dim)
scores = scores.masked_fill(mask == 0, float("-inf"))
weights = torch.softmax(scores, dim=-1)
context = weights @ V

# 拼回所有头，再投影回 d_model
out = W_o(context.transpose(1, 2).contiguous().view(B, L, d_model))
[B, L, d_model]→[B, H, L, d_head]→[B, H, L, L]→[B, H, L, d_head]→[B, L, d_model]

实现顺序

① Embedding＋Position → ② Multi-Head Attention → ③ Add & Norm → ④ FFN → ⑤ Add & Norm → ⑥ 堆 Encoder / Decoder → ⑦ 生成 Mask → ⑧ Linear＋Softmax。

两个最常见 Bug

形状错：忘记 transpose 或拼头前没 contiguous。
Mask 错：广播维度不对，或把允许位置与禁止位置写反。

08 · Interview bank

28 个常见面试题

答案按“先结论、再原因、最后边界”组织。点击问题展开，适合快速复习。

🗺️

架构总览

1. 什么是 Transformer？为什么使用它？
Transformer 是以 Attention 为主要信息交互机制的序列建模架构。它提高训练并行度、缩短远距离依赖的路径，并能高效利用 GPU。代价是标准 Self-Attention 对序列长度有 O(n²) 时间与内存开销。
一句话：它用全局矩阵化的信息检索，替代 RNN 的逐步状态传递。
2. Transformer 的主要组成部分是什么？
原始模型包括 Encoder、Decoder、Embedding、位置编码、多头 Attention、FFN、残差连接、LayerNorm，以及输出 Linear＋Softmax。Encoder 负责理解输入，Decoder 在因果约束下读取输入记忆并生成目标。
3. Encoder 模块怎样工作？
每层先用多头 Self-Attention 让输入位置互相交换信息，再用逐位置 FFN 做非线性加工；子层外包裹残差与归一化。多层堆叠形成逐渐抽象的上下文表示。
4. Encoder 和 Decoder 如何交互？
通过 Cross-Attention：Decoder 当前隐藏状态产生 Q，Encoder 最终输出产生 K 与 V。Decoder 用自己的需求查询输入句子的“阅读笔记”。
5. Decoder 与 Encoder 的 Attention 有什么不同？
Encoder Self-Attention 通常双向看完整输入；Decoder Self-Attention 带 causal mask，只能看当前与过去；Decoder 还多一层 Cross-Attention 读取 Encoder。
🔎

Attention 与多头

6. 什么是 Self-Attention？为什么使用？
同一序列同时生成 Q/K/V，让每个位置按相关性汇总其他位置的 V。它能直接连接远距离位置并行训练，但长序列下计算与显存成本为平方级。
7. 什么是 Multi-Head Attention？
多组 WQ/WK/WV 把表示投影到不同子空间，各头并行计算 Attention，结果拼接后再线性映射。它让同一层能同时建模多类关系。
8. 为什么不能只用一个头？
一个头仍能工作，但容易把多种关系压进同一套权重。多头提供多个表示子空间，让语法、指代、局部搭配、远距离关系等可以同时被捕捉。
9. 多头时为什么每个 head 要降维？
通常令 d_head=d_model/H，使 H 个头拼接后仍回到 d_model，整体计算量与单个全维头同量级。若每头都保持 d_model，参数量、显存和计算会近似随头数放大。
10. 为什么 Q、K 使用不同参数矩阵？
查询角色与被检索角色并不对称，独立投影能学习不同特征空间，提高表达能力。共享矩阵不会必然导致只关注自己，但会增加不必要的约束。
11. 为什么用点积而不是加性 Attention？
缩放点积能用一次批量矩阵乘法高效实现。加性 Attention 使用可学习 MLP 计算兼容度，并非直接相加；它也有效，但在现代硬件上通常不如点积高效。
12. 为什么 Softmax 前要除以 √dₖ？
点积方差随维度增大；过大的 logits 会让 Softmax 饱和、梯度变小。除以 √dₖ 把分数恢复到更稳定的尺度。

位置、残差与归一化

13. 什么是位置编码？
它向 token 表示注入位置信息，弥补 Self-Attention 对排列天然不敏感的问题。原论文用固定正弦/余弦，也尝试可学习绝对位置；现代模型常用 RoPE 或 ALiBi。
14. 为什么使用正弦和余弦？
无需学习参数，可为任意位置计算；多频率组合提供从局部到全局的位置信号，而且某些相对位移能通过线性关系表达。它不是唯一选择。
15. 还可以怎样表示位置？
可学习绝对位置、相对位置偏置、RoPE、ALiBi 等。取舍涉及外推长度、计算方式、任务类型和是否需要显式相对距离。
16. Embedding 为什么乘 √d_model？
原论文把词向量放大到与位置编码相加时更合适的尺度，并非为了压小数值。随后再由后续层和归一化控制整体尺度。
17. 残差连接有什么作用？
保留原表示并为梯度提供短路径，让子层专注学习修改量，缓解深层网络退化和优化困难。它允许某层学到近似零修改，但不等于程序硬跳过这层。
18. LayerNorm 与 BatchNorm 有什么区别？
LayerNorm 对单个样本、单个 token 的特征维归一化，不依赖 batch 统计，适合变长序列和小 batch；BatchNorm 沿 batch 统计通道分布，训练/推理维护不同统计量，在 CNN 中更常见。
19. LayerNorm 放残差前还是后？
原始 Transformer 是 Post-LN：LN(x+Sublayer(x))。现代 LLM 多为 Pre-LN：x+Sublayer(LN(x))，通常更利于深层训练。应根据具体架构回答，不能笼统说固定在某一侧。

FFN、Mask 与训练

20. FFN 的作用是什么？激活函数是什么？
Attention 负责跨位置混合，FFN 在每个位置上做相同的非线性特征变换，扩展再压回维度。原论文使用 ReLU；后续常见 GELU、SiLU、SwiGLU。
21. Padding Mask 有什么作用？
批处理时短句会补 PAD。Mask 把这些无意义位置的 Attention logits 设为极小值，使 Softmax 后权重为 0，避免污染真实 token 表示。
22. Decoder 为什么需要 Causal Mask？
训练时整段目标答案已知，如果不遮住未来位置，模型会偷看正确答案。下三角遮罩保证第 t 个位置只能使用 ≤t 的信息，与自回归推理条件一致。
23. Transformer 可以并行化吗？Decoder 呢？
Encoder 训练可对位置并行。Decoder 训练也能借助 causal mask 并行计算所有目标位置；但自回归推理时必须逐 token 生成，无法直接并行时间步，通常用 KV Cache 避免重复算历史 K/V。
24. 训练中为什么使用 Warmup、Dropout 和 Label Smoothing？
Warmup 稳定初期优化；Dropout 减少路径共适应、抑制过拟合；Label Smoothing 避免模型对 one-hot 标签过度自信，并可能改善泛化和 BLEU。

能力、边界与分词

25. Transformer 怎样处理长距离依赖？
Self-Attention 允许任意位置在一层内直接交互，路径短于 RNN。但这不代表长上下文已被彻底解决：注意力稀释、位置外推和 O(n²) 成本仍是挑战。
26. Transformer 的主要优点是什么？
训练并行度高、远距离交互路径短、扩展性强、架构通用，核心矩阵计算适合加速器，并能迁移到语言、视觉、语音、多模态等任务。
27. Transformer 的主要缺点是什么？
标准 Attention 随序列长度平方增长；训练数据和算力需求大；自回归生成慢；位置与长度外推需要专门设计；模型内部决策也不等同于自然语言可解释推理。
28. WordPiece、BPE 与 BERT 的 Mask 有什么关系？
BPE/WordPiece 是子词分词策略，用有限词表处理生词；BERT 的 MLM Mask 是训练目标，隐藏部分 token 内容但保留双向 Attention。Causal Attention Mask 则限制信息流，禁止看未来。两类 Mask 解决的问题不同。

10 · Final card

最后只记住这 7 句话

  1. Transformer 的核心变化：用 Attention 作为主要依赖建模方式，去掉循环计算。
  2. Q / K / V：Q 提需求，K 做索引，V 带回内容；它们都是上下文向量的不同投影。
  3. 完整公式：匹配 QKᵀ → 缩放 √dₖ → Mask → Softmax → 汇总 V。
  4. 多头 vs 多层：多头是同一轮并行多视角，多层是多轮串行精修。
  5. 残差＋归一化：保留旧稿、学习修改量，并持续校准数值尺度。
  6. Mask：Padding Mask 屏蔽补齐符；Causal Mask 防止偷看未来。
  7. 最大边界：标准 Attention 的全局交互很强，但长序列成本是 O(n²)，自回归推理仍需逐词生成。
