01 · THE BIG PICTURE

先把训练链路放进一张地图

这些词不在同一个层级：预训练和微调是训练阶段；LoRA/QLoRA 是微调方法；合成数据是数据来源；CoT 是样本或输出的推理表达方式；泛化是最终想得到的能力。

STAGE 01预训练海量文本、代码或多模态数据，学习语言与世界规律。
STAGE 02监督微调 SFT用“指令 → 理想回答”教会模型按任务要求作答。
STAGE 03偏好与对齐让回答更符合人类偏好、安全要求和业务规范。
STAGE 04评测与部署检查真实场景效果、泛化、成本与风险。
一句话：预训练决定“底子有多厚”，微调决定“在这个任务上怎么做”，评测决定“是不是真的学会，而不是背会”。
02 · PRETRAINING

预训练：先从海量数据中学通用规律

语言模型常见的预训练目标是根据上下文预测下一个 token。它没有直接背一本“知识字典”，而是在大量预测任务中调整参数，逐渐形成语言、模式与部分世界知识。

输入

大规模、广覆盖的数据

网页、书籍、代码、论文、对话等。数据清洗、去重和配比会直接影响模型学到什么。

输出

具备通用能力的基座模型

它能续写和完成很多任务，但不一定会稳定遵循指令，也不一定符合具体业务规范。

简化目标next-token prediction
输入：人工智能正在改变软件开发的 ____
目标：预测下一个 token，例如“方式”

loss = -log P("方式" | "人工智能正在改变软件开发的")

# 重复数十亿次预测，模型参数逐渐编码通用模式
预训练不等于事实数据库。模型学习的是概率规律，可能知识过时、记忆不准或生成幻觉；需要 RAG、工具调用和评测补足。
03 · FINE-TUNING

微调：在已有能力上改变行为

微调继续用任务数据训练模型。区别在于：你可以更新全部参数，也可以只训练很小的适配器。

方法基座权重训练内容资源成本适合场景
全量微调参与更新几乎全部参数最高数据、算力充足且需要深度改变模型
LoRA冻结，常用 FP16/BF16低秩矩阵 A、B较低多数领域适配、格式和风格任务
QLoRA冻结，通常存为 4-bit较高精度的 LoRA 适配器更低显存单卡微调更大模型
LoRA

高清教材 + 少量批注

基座模型以较高精度保存并冻结，只训练旁路的小矩阵。实现直接、训练通常更稳定。

QLoRA

压缩教材 + 高清批注

冻结的基座模型量化到 4-bit 来省显存；LoRA 参数仍以较高精度训练，不是把所有训练都变成 4-bit。

QLoRA = 量化基座 + LoRA。它首先解决的是显存问题，不代表效果一定优于普通 LoRA；是否合适要看模型大小、硬件和验证集。
04 · LOW-RANK LAB

LoRA 怎么把大矩阵变小？

对于一个 4096 × 4096 的线性层，LoRA 不直接训练完整的更新矩阵 ΔW，而是训练两个窄矩阵，使 ΔW = BA。拖动秩 r，观察参数量变化。

秩 r 的直觉：这次任务允许模型沿多少个独立“变化方向”调整。r=8 不是只训练 8 个参数，而是让信息经过宽度为 8 的瓶颈。
一个重要细节：实际训练通常不是先得到完整 ΔW，再把它机械拆开。LoRA 直接初始化 A、B，并通过反向传播共同学习它们；只是从数学上保证 BA 的秩最多为 r。

05 · CHOOSING RANK

怎么定秩：选验证集够用的最小值

秩不是越大越好。更大的 r 带来更强表达能力，也带来更多参数、显存、训练时间和小数据过拟合风险。

r = 4–8简单格式、语气或小数据任务
r = 8–16常见领域问答和客服适配
r = 16–32代码、复杂任务或多个子能力
r = 32–64任务差异大且数据充足时再试
固定数据切分
训练 r=8
对比 16 / 32
看真实验证指标
选最小够用值

秩太小的信号

  • 训练集也学不好，loss 很早停滞
  • 格式、术语或复杂任务仍明显欠拟合
  • 提高 r 后训练集和验证集都改善

秩太大的信号

  • 训练集表现很好，验证集却下降
  • 输出死记模板，换种问法就失效
  • 提高 r 只增加成本，不改善真实指标
还要一起看 target_modules。只训练 q_proj/v_proj 与同时训练 q/k/v/o、MLP 层，即使秩相同，总参数量和适配能力也不同。
06 · LOSS

Loss：模型离正确答案还有多远

训练时，模型先做预测，再用损失函数把“预测有多错”压缩成一个数字。优化器根据这个数字计算参数应该往哪个方向调整。

模型给正确答案的概率越高，Loss 越小。拖动滑杆看看变化。

0.105Loss = −log(p)预测比较有把握
p = 90%Loss ≈ 0.105，正确答案概率高。
p = 10%Loss ≈ 2.303，模型明显判断错了。
p = 1%Loss ≈ 4.605，而且错得很自信。
语言模型的简化损失cross entropy
loss = -log P(正确 token)

预测 → 计算 Loss → 反向传播梯度 → 优化器更新参数 → 再预测

# 实际训练通常对一个 batch 中参与训练的 token loss 求平均

训练 Loss

在模型见过并参与学习的数据上计算。它持续下降，说明模型越来越会拟合训练样本。

验证 Loss

在不参与参数更新的数据上计算。它更能判断模型是否学到了可以迁移的新规律。

判断过拟合的典型信号：训练 Loss 继续下降，但验证 Loss 开始上升。这意味着模型越来越会做训练题，却越来越不会做新题。
Loss 低不等于业务效果一定好。它是训练目标的代理指标；最终仍要看正确率、事实性、格式合规率、安全性和真实用户任务表现。
07 · GENERALIZATION

泛化：不是把训练题背熟，而是学到规律

泛化好，意味着模型在没见过、但来自真实业务分布的新输入上仍然表现稳定。

健康信号训练集和验证集同步改善；换表达、换顺序、换边界条件后仍然正确。
过拟合信号训练 loss 继续下降，验证效果反而变差；输出高度模板化，对轻微改写很敏感。
先把数据切分做对相似样本、同一用户或同一文档切片不要跨训练集和测试集，避免数据泄漏。
提高质量与覆盖，而不只追求数量覆盖真实表达、边界条件、拒答和错误示例；清洗错误标注与重复样本。
控制训练强度使用较小秩、合理学习率、少量 epoch、weight decay、dropout 和早停。
用真实任务指标验收同时观察正确率、格式合规率、事实错误率与人工偏好，不只看训练 loss。
08 · SYNTHETIC DATA

合成数据：人为生成的训练样本

它不是直接来自真实业务记录或逐条人工标注，而是由规则、程序或另一个模型生成，用来补充覆盖面。

模型生成

扩写问法与答案

从少量优质种子样本生成口语、错别字、多轮对话或不同难度版本。

规则生成

制造边界条件

用模板和程序组合订单状态、金额、时间、异常码等可验证字段。

文档生成

构造问答对

从知识库生成问题、答案与证据，但必须核对答案是否真的被原文支持。

它擅长补什么

  • 真实数据稀少的长尾问题
  • 不同措辞、语言和输入格式
  • 安全拒答和异常场景
  • 可程序验证的组合数据

它容易带来什么问题

  • 继承生成模型的错误和偏见
  • 样本看似很多，实质模板重复
  • 语言风格单一，模型学会“机器腔”
  • 与最新业务规则不一致
稳妥配方：真实高质量数据定义任务与边界，合成数据补覆盖；生成后做事实校验、去重、质量打分和人工抽检，并保留一份完全真实且未参与训练的测试集。
09 · CHAIN OF THOUGHT

CoT：把复杂问题拆成中间步骤

CoT 是 Chain of Thought（思维链）。在训练数据里，它常表现为“问题 + 中间推导 + 答案”，帮助模型学习多步数学、逻辑和规划任务。

示例brief, verifiable reasoning
问题：原价 100 元，先打 8 折，再减 10 元，实付多少？

关键步骤：
1. 折后价 = 100 × 0.8 = 80
2. 实付价 = 80 - 10 = 70

答案：70 元

训练上的价值

用高质量、可验证的中间步骤提供更密集的学习信号，尤其适合需要组合推导的任务。

生产输出的原则

更推荐输出结论、关键依据、公式和可检查步骤，而不是要求模型暴露冗长的内部推理过程。

错误 CoT 也会教坏模型。合成推理数据必须验证步骤与答案；“写得很长”不等于“推得正确”。
10 · GLOSSARY

最后用术语表收口

Pretraining
用大规模数据学习通用模式，产出基座模型。
Fine-tuning / SFT
用任务样本继续训练，使模型按指令完成特定任务。
PEFT
参数高效微调，只训练少量新增或选定参数；LoRA 是其中一种。
LoRA
Low-Rank Adaptation，用低秩矩阵 BA 表示权重增量。
QLoRA
量化冻结的基座模型，同时训练 LoRA 适配器。
Rank / r
低秩瓶颈宽度，可理解为允许更新使用的变化方向数。
Loss
衡量模型预测与训练目标差距的数值；训练通过优化参数来降低它。
Generalization
模型在未见过的真实分布数据上仍然有效的能力。
Synthetic Data
由模型、规则或程序生成，而非直接采集的训练数据。
CoT
Chain of Thought，将复杂任务表示为连续的中间推导步骤。
Validation Set
不参与参数训练，用来选超参数和判断过拟合的数据集。
当前学习结论：先用高质量数据定义任务，再用最小够用的适配能力学习它；最后用独立、真实的验证集检查模型学到的是规律，还是模板。
