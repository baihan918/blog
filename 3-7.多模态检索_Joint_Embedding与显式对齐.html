Joint Embedding 与显式对齐，究竟怎么选？

别把它们当成非此即彼：独立编码解决海量召回，动态交互解决细粒度判断。先看两种架构怎样计算，再亲手调整数据规模与 Top-K。

01 · Mental Model

先记职责，不背术语

假设知识库有一千万张图片。系统既要在几十毫秒内缩小范围，又要看懂“左边的人穿红衣、手里拿杯子”这种局部关系。

Dual Encoder / Joint Embedding

文本与图片分别编码为固定向量，放进同一个可比较空间。在线只编码 Query，然后用余弦相似度和 ANN 搜索。

  • Document 可提前离线计算
  • 适合百万到亿级全库召回
  • 全局向量可能压掉局部关系

Cross Encoder / Cross-Attention

保留 Text Token 与 Image Patch，让 Query 针对每个候选进行动态交互并输出匹配分数。

  • 擅长属性、对象和空间关系
  • 计算依赖 Query × Document
  • 适合对有限 Top-K 候选精排
生活类比：Joint Embedding 像先按“可能是技术书”从整座图书馆筛出 200 本；Cross-Attention 像逐本翻目录，确认哪 10 本真正回答当前问题。
02 · Architecture

切换架构，看信息在哪里相遇

观察 Query 与 Document 是在编码后才比较，还是从 Token / Patch 层就一起计算。这决定了能否预计算，也决定了表达上限。

03 · Concept Dimensions

最容易混淆的三个维度

“用了对比学习”不等于“检索时发生 Cross-Attention”。训练目标、编码结构、推理交互是三个不同问题。

表示空间

不同模态是否映射到一个可直接比较的空间？这才是 Joint Embedding 关注的问题。

训练方式

Contrastive Learning 让正样本更近、负样本更远。它是一种训练目标，不规定推理结构。

推理交互

Query 与 Document 能否独立编码？是否必须成对进入模型？这决定 ANN 可用性与在线成本。

面试加分点：CLIP 可以用 Contrastive Loss 训练 Joint Embedding，但推理阶段依然独立编码。Contrastive Alignment 与 Cross-Attention 不是同一个分类维度。

06 · Hard Negative

哪一个负样本最能教会模型？

训练 Query：“穿红衣服拿咖啡的人”。请选择最有价值的 Hard Negative。

Hard Negative 应该“很像，但在关键条件上不匹配”。
为什么重要：如果负样本全是汽车这类 Easy Negative，模型只要学会粗粒度类别就能过关；加入“咖啡 vs 手机”会迫使它关注决定相关性的细节。
07 · Engineering Constraints

两条链路分别优化什么

Joint Embedding / Recall

  • Embedding Dimension 与归一化
  • Similarity Metric：cosine / dot product
  • Contrastive Learning 与温度系数
  • Hard Negative Mining
  • ANN：HNSW / IVF
  • 量化、索引内存、Recall@K

Cross-Attention / Rerank

  • Text Token 与 Image Patch 数量
  • Top-K Candidate 数量
  • Attention 计算量
  • GPU 显存与 Batch Size
  • 图片分辨率 / PDF 页数
  • 模型大小与在线延迟
核心性能边界pseudo
# Dual Encoder：一次编码 + 索引搜索
query_vec = text_encoder(query)
candidates = vector_db.ann_search(query_vec, top_k=200)

# Cross Encoder：只对候选逐对打分
scores = [reranker.score(query, doc) for doc in candidates]
top_n = sort_by_score(candidates, scores)[:10]

09 · Interview Answer

90 秒面试回答模板

在大规模多模态检索中，我不会把 Joint Embedding 和 Cross-Attention 当成完全竞争的方案。

Joint Embedding / Dual Encoder 让 Query 与 Document 独立编码，因此 Document 向量可以离线计算并建立 ANN 索引，适合百万到亿级数据的第一阶段召回；代价是固定维度的全局向量可能损失局部对象、属性和空间关系。

Cross-Attention 让 Query Token 与 Image Patch 或 Document Token 动态交互，细粒度匹配更强；但最终分数依赖 Query × Document，不能直接高效扫描整个知识库。

所以生产上我会使用 Dual Encoder + Contrastive Alignment 做 ANN Recall，再用 Cross-Attention Multimodal Reranker 对 Top-K 精排。另外，Contrastive Learning 是训练目标，Cross-Attention 是推理交互结构，两者不是同一个分类维度。
