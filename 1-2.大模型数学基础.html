一、先看全局：四类数学各自负责什么#

01 线性代数

把文字变成数字，并批量完成信息变换。

关键词：向量、矩阵、点积
02 微积分

测量错误变化方向，告诉参数应该怎么改。

关键词：导数、梯度、链式法则
03 概率统计

表达模型对下一个词有多确定。

关键词：分布、期望、方差
04 优化器

根据梯度反复更新参数，让错误越来越小。

关键词：SGD、学习率、Adam

可以把训练大模型想象成教一个学生做题：

数学工具 类比 在大模型中的工作
线性代数 把题目整理成表格 表示词语、批量变换特征
微积分 判断错题应该往哪个方向改 计算每个参数对错误的影响
概率统计 给多个答案分配可信度 输出下一个 Token 的概率
优化器 按照改错建议调整学习方法 更新模型参数，降低损失
一句话：向量装信息，矩阵做变换；概率给答案，损失判好坏；梯度指方向，优化器迈步子。

二、线性代数：把语言变成可以计算的数字#

2.1 为什么大模型离不开线性代数#

计算机不能直接理解“猫很可爱”，它只能计算数字。大模型首先要把词或 Token 转换成一串数字，然后通过大量矩阵运算处理这些数字。

线性代数主要解决两个问题：

  1. 怎样表示信息：使用向量表示一个词、一个 Token 或一句话的特征。
  2. 怎样变换信息：使用矩阵把输入特征转换成模型需要的新特征。

在大模型中经常遇到：

  • 词向量和 Embedding
  • 神经网络的线性层
  • 注意力中的 Q、K、V
  • 模型参数矩阵
  • 降维和模型分析中的 SVD、特征值分解

2.2 向量：一张“特征清单”#

向量可以先理解成一个有顺序的数字列表：

一个三维向量
x = [1, 2, 3]

假设我们用三个维度描述一个词：

直觉推演 
[动物属性, 可爱程度, 科技属性]

那么可以想象：

直觉推演 
“猫”   → [0.95, 0.90, 0.05]
“小狗” → [0.93, 0.86, 0.04]
“芯片” → [0.02, 0.01, 0.98]

“猫”和“小狗”的向量比较接近，“猫”和“芯片”差距较大。真实大模型的向量通常有几百到几千维，每一维也不一定能被人直接命名，但“相似含义靠得更近”的直觉依然成立。

生活类比

向量就像一个人的体检报告：身高、体重、心率是不同维度。仅凭一个数字无法描述完整的人，一组数字合起来才形成特征。

2.3 向量加法：把对应位置的信息相加#

Notebook 中定义：

Python 
import numpy as np

a = np.array([1, 2, 3])
b = np.array([4, 5, 6])

add_result = a + b
print(add_result)  # [5 7 9]

计算时按位置相加：

直觉推演 
[1, 2, 3] + [4, 5, 6]
= [1+4, 2+5, 3+6]
= [5, 7, 9]

两个向量必须形状兼容。不能随意把三维向量和四维向量逐项相加。

2.4 点积：衡量两个方向有多“对得上”#

两个向量点积时，对应位置先相乘，再把结果相加：

点积
a · b = 1×4 + 2×5 + 3×6 = 32
Python 
dot_result = np.dot(a, b)
print(dot_result)  # 32

点积结果是一个数字。它常用于表示两个向量方向的匹配程度：

  • 点积较大：两个方向比较一致。
  • 点积接近 0：两个方向接近垂直，关联较弱。
  • 点积为负：两个方向相反。

不过，点积还会受到向量长度影响。只想比较方向时，通常会先归一化，或者使用余弦相似度。

2.5 矩阵：一次处理多组信息#

矩阵可以理解成由多行向量组成的表格：

W =
123 456
2 行 × 3 列

矩阵 W 有两行三列，形状写作 (2, 3)。它可以接收一个三维输入，并产生一个二维输出。

2.6 矩阵乘向量：每一行都和输入做一次点积#

Notebook 的代码使用：

Python 
W = np.array([[1, 2, 3],
              [4, 5, 6]])
x = np.array([1, 2, 3])

y = W.dot(x)
print(y)  # [14 32]

拆开计算：

直觉推演 
第一行：1×1 + 2×2 + 3×3 = 14
第二行：4×1 + 5×2 + 6×3 = 32

结果：y = [14, 32]

Notebook 的讲解图片用了另一个输入 x = [1, 0, -1]：

直觉推演 
第一行：1×1 + 2×0 + 3×(-1) = -2
第二行：4×1 + 5×0 + 6×(-1) = -2

结果：y = [-2, -2]

这两组结果并不冲突：矩阵 W 相同，但输入向量 x 不同，所以输出也不同。

形状检查规则(2 × 3) 矩阵×(3 × 1) 向量→(2 × 1) 向量

中间的两个 3 必须相同，结果保留外侧的 2 和 1。

2.7 它怎样出现在 Transformer 中#

注意力机制可以先用三步理解：

直觉推演 
1. 每个 Token 通过矩阵变换得到 Q、K、V
2. Q 和 K 做点积，计算“我应该关注谁”
3. 注意力权重乘以 V，汇总真正需要的信息

简化表达：

Scaled Dot-Product Attention
Attention(Q, K, V) = softmax(QKᵀ / √d) · V

现在不需要推导这个公式，只要记住：矩阵变换负责生成信息，点积负责比较相关性，概率权重负责决定关注比例。

三、微积分：告诉模型参数应该往哪里改#

3.1 为什么训练模型需要微积分#

模型第一次预测时通常很不准确。训练就是不断修改参数，让预测错误越来越小。

这需要回答：

  1. 当前错了多少？——由损失函数计算。
  2. 参数稍微变化，损失会怎样变化？——由导数和梯度回答。
  3. 参数下一步往哪里走？——通常沿梯度的反方向。

3.2 导数：某一点的“即时变化速度”#

生活类比

汽车仪表盘显示的瞬时速度，就是“路程对时间的导数”。它不是整段路的平均速度，而是此刻变化得有多快。

对函数 f(w) 来说，导数 f′(w) 表示参数 w 稍微变化时，函数值变化得有多快：

  • 导数大于 0：w 增大时，函数倾向于上升。
  • 导数小于 0：w 增大时，函数倾向于下降。
  • 导数等于 0：当前位置可能是最低点、最高点或平坦区域。

3.3 梯度：多维世界里的方向箭头#

一个模型有很多参数，损失函数不只依赖一个变量。这时，把每个参数的偏导数组合起来，就得到梯度：

梯度
∇L = [∂L/∂w₁, ∂L/∂w₂, …, ∂L/∂wₙ]

梯度可以想象成一个箭头，它指向函数值上升最快的方向。我们想让损失下降，所以要朝梯度的反方向走。

3.4 梯度下降：顺着下坡方向一步步走#

更新规则：

参数更新
新参数 = 旧参数 − 学习率 × 梯度
w ← w − η · f′(w)

其中：

  • w：当前参数。
  • f′(w)：当前位置的梯度。
  • η：学习率，决定每一步走多远。

3.5 Notebook 示例：寻找 (w - 2)² 的最低点#

函数：

f(w) = (w − 2)²
最低点显然在 w = 2，此时 f(w) = 0

它的导数是：

直觉推演 
f′(w) = 2(w - 2)

Notebook 从 w = 10 开始，学习率为 0.1：

Python 
def f(w):
    return (w - 2) ** 2

def grad_f(w):
    return 2 * (w - 2)

learning_rate = 0.1
w = 10.0

for i in range(10):
    w = w - learning_rate * grad_f(w)
    print(i + 1, w, f(w))
迭代 参数 w 损失 f(w) 发生了什么
开始 10.0000 64.0000 离最低点很远
1 8.4000 40.9600 向 2 靠近
2 7.1200 26.2144 损失继续下降
5 4.6214 6.8719 已明显接近
10 2.8590 0.7379 还没到 2，但越来越近
可操作实验

亲手走一次梯度下降

当前 w10.000
当前损失64.000
当前梯度16.000
已走步数0

试着改变学习率，观察参数靠近最低点的速度。

3.6 学习率为什么重要#

学习率 表现 类比
太小 能下降，但速度非常慢 下山时每次只挪一厘米
合适 稳定而较快地接近最低点 步幅适中，持续下坡
太大 可能越过最低点、来回震荡甚至发散 一步跨过山谷，跳到对面山坡

在上面的实验中，把学习率调到接近 0.95，你会看到参数在最低点两侧大幅来回跳动。对于这个简单函数，学习率超过 1 时会直接发散，因此滑块上限设置为 0.95。

3.7 它怎样出现在大模型训练中#

真实模型有数十亿甚至更多参数。反向传播会利用链式法则，从最终损失一路向前计算每个参数的梯度：

直觉推演 
预测概率
  → 计算损失
  → 反向传播
  → 得到每个参数的梯度
  → 优化器更新参数

我们不需要手算每个导数，PyTorch、TensorFlow 等框架会自动求导。但理解梯度的意义，才能理解“模型为什么会学到东西”。

四、概率与统计：模型不是选答案，而是分配可能性#

4.1 为什么大模型需要概率#

同一句话可能有多个合理的下一个词：

直觉推演 
“今天天气很……”

后面可能是“好”“冷”“热”“糟糕”。大模型不会先得到一个唯一答案，而是给候选 Token 分配概率。

概率与统计帮助我们：

  • 描述数据的分布。
  • 衡量预测的不确定性。
  • 从概率分布中选择下一个 Token。
  • 使用最大似然估计训练参数。
  • 分析均值、波动和异常情况。

4.2 随机变量：结果还没发生时的占位符#

随机变量是“结果尚未确定，但可能取若干值”的变量。例如抛硬币：

直觉推演 
X = 1：正面
X = 0：反面

如果正面概率为 p：

伯努利分布
P(X=1)=p，P(X=0)=1−p

4.3 期望：重复很多次后的平均结果#

期望不是“下一次一定出现的结果”，而是重复很多次后的平均值。

对于上面的硬币：

直觉推演 
E[X] = 1×p + 0×(1-p) = p

如果 p = 0.7，抛很多次以后，正面的比例会逐渐靠近 70%；但下一次仍然可能是反面。

4.4 方差：结果围绕平均值波动多大#

方差衡量数据离期望值的平均偏离程度。伯努利变量的方差是：

Var(X) = p(1 − p)
  • 当 p = 0 或 p = 1，结果完全确定，方差为 0。
  • 当 p = 0.5，正反最不确定，方差最大，为 0.25。
可操作实验

改变正面概率，观察期望与方差

正
正面70%
反面30%
期望 E[X]0.700
方差 Var(X)0.210

结果偏向正面，但仍保留一定不确定性。

4.5 概率分布：给所有候选结果分配概率#

语言模型会给词表中的每个候选 Token 一个概率，并且所有概率相加等于 1。

例如上下文是“我今天去”：

候选 Token 概率 直觉
学校 0.45 最可能
公司 0.30 也很合理
公园 0.15 有可能
月球 0.01 语法可接，但语义罕见
其他所有 Token 0.09 剩余可能性

所有概率相加：

直觉推演 
0.45 + 0.30 + 0.15 + 0.01 + 0.09 = 1.00

4.6 Softmax：把任意分数变成概率#

模型最后一层先输出一组原始分数，叫作 logits。这些分数可以为负，也不需要相加等于 1。

假设三个候选词的分数是：

直觉推演 
logits = [2, 1, 0]

Softmax 先做指数运算，再除以总和：

Softmax
Pᵢ = eᶻⁱ / Σⱼeᶻʲ

得到近似概率：

直觉推演 
[0.665, 0.245, 0.090]

Softmax 保留“分数越高，概率越大”的顺序，同时保证每个结果在 0～1 之间且总和为 1。

4.7 最大似然：让训练文本中的正确答案越来越可能#

假设训练文本中的正确下一个词是“学校”。模型给“学校”的概率越高，就说明模型越能解释这条训练数据。

最大似然估计（MLE）的目标是：找到一组参数，让已经观察到的数据出现概率最大。

实际训练通常最小化负对数似然或交叉熵：

单个正确 Token 的损失
Loss = −log(P(正确 Token))
正确 Token 的概率 损失约为 含义
0.90 0.105 模型很有把握，惩罚小
0.70 0.357 方向正确，还有提升空间
0.10 2.303 模型不看好正确答案，惩罚大
0.01 4.605 严重预测错误，惩罚很大

最大后验估计（MAP）则是在似然之外，再加入对参数的先验认识。可以粗略理解为：既要解释现有数据，也不要偏离合理范围太远。

4.8 温度：控制概率分布的“尖锐程度”#

生成文本时常见的 temperature 不会让模型学到新知识，它只是调整采样前的概率分布：

  • 温度低：高概率 Token 更突出，回答稳定、保守。
  • 温度高：概率分布更平，低概率 Token 更容易被选中，回答更多样。

温度不是“准确度旋钮”。事实问答通常适合较低温度，创意写作可以适当提高。

五、优化器：拿着梯度，真正更新参数#

5.1 梯度和优化器有什么区别#

这两个概念经常被混在一起：

概念 回答的问题
梯度 每个参数对损失有什么影响？往哪个方向会升高？
优化器 已经知道梯度后，参数具体更新多少？是否参考过去的梯度？

梯度像导航给出的方向，优化器像真正开车的人：它还要决定速度、惯性和每条路的步幅。

5.2 三种常见更新方式#

批量梯度下降（Batch Gradient Descent）#

每次使用全部训练数据计算一次梯度。

  • 优点：方向稳定。
  • 缺点：数据很大时，一步的计算成本太高。

随机梯度下降（SGD）#

每次只随机取一个样本计算梯度。

  • 优点：更新快、占用内存少。
  • 缺点：方向抖动明显。

小批量梯度下降（Mini-batch）#

每次取一小批样本，是实际深度学习中最常见的折中方案。

  • 比单样本稳定。
  • 比全量数据高效。
  • 可以发挥 GPU 并行计算能力。

5.3 Adam：同时考虑惯性和参数自己的步幅#

Adam 可以先用两个类比理解：

  1. 动量：下山时不仅看此刻的坡度，还参考前面几步的方向，减少左右摇摆。
  2. 自适应学习率：经常出现大梯度的参数走小一点，梯度较小的参数可以走大一点。

因此 Adam 在复杂、高维问题中通常比最基础的 SGD 更容易快速得到可用结果。大模型训练还会配合学习率预热、衰减、梯度裁剪、权重衰减等策略。

Notebook 构造的数据大致遵循：

真实规律

模型不知道 3.5 和 1.2，只使用：

直觉推演 
预测值 ŷ = wx + b

训练目标是学出合适的 w 和 b。

5.5 损失函数：用均方误差衡量直线画得好不好#

均方误差（MSE）把每个预测误差平方后取平均：

Mean Squared Error
L(w,b) = (1/N) Σᵢ(wxᵢ + b − yᵢ)²

为什么要平方：

  • 正误差和负误差不会互相抵消。
  • 大误差会受到更强惩罚。
  • 函数平滑，便于求导。

5.6 一次训练循环发生了什么#

Python 
# 1. 前向计算：用当前参数预测
y_pred = w * X + b

# 2. 计算损失
loss = np.mean((y_pred - y) ** 2)

# 3. 计算 w 和 b 的梯度
dw = np.mean(2 * (y_pred - y) * X)
db = np.mean(2 * (y_pred - y))

# 4. 参数更新
w -= learning_rate * dw
b -= learning_rate * db

四步可以记成：

1预测
Forward → 2算错多少
Loss → 3计算梯度
Backward → 4更新参数
Update

六、把四部分串起来：大模型一次训练发生了什么#

文本“我喜欢猫”
→
Token ID[42, 318, 907]
→
向量与矩阵Embedding + Transformer
→
概率分布Softmax
→
损失与正确答案比较
→
梯度反向传播
→
更新参数Adam / SGD

逐步解释：

  1. 分词：把文本拆成 Token，并映射为整数 ID。
  2. Embedding：根据 ID 查表，得到每个 Token 的向量。
  3. 矩阵运算：Transformer 不断变换和融合上下文信息。
  4. 输出概率：模型产生 logits，Softmax 将它们变成概率。
  5. 计算损失：检查正确 Token 的概率是否足够高。
  6. 反向传播：利用微积分计算每个参数的梯度。
  7. 优化器更新：根据梯度和学习率调整参数。
  8. 重复训练：在大量文本上反复执行，模型逐渐掌握统计规律。
训练的本质：模型先用当前参数做预测，再根据错误计算梯度，最后用优化器更新参数。所谓“学习”，就是让大量参数朝着更少犯错的方向移动。

七、常见误区#

误区 1：向量的每一维都有明确的人类含义#

教学时可以给每一维起名字帮助理解，但真实 Embedding 的单个维度通常没有稳定、独立的人类语义。意义更多分布在整个向量及其组合中。

误区 2：点积大就一定语义相似#

点积同时受到方向和向量长度影响。检索场景常使用归一化向量和余弦相似度，还要结合模型训练方式判断。

误区 3：梯度等于参数更新量#

梯度只提供局部变化信息。真正更新多少还取决于学习率、优化器状态、权重衰减、梯度裁剪等因素。

误区 4：损失下降就代表模型回答一定正确#

训练损失下降只说明模型更适应训练目标。还需要验证集、测试集和真实任务评估，检查泛化能力、事实性、安全性等。

误区 5：概率最高的词一定会被选中#

贪心解码会选概率最高的 Token，但温度采样、Top-k、Top-p 等策略可能选择其他候选词，以换取多样性。

误区 6：优化器能保证找到全局最优解#

深度学习的损失空间非常复杂。优化器通常只能找到一个足够好的区域，不能保证找到唯一的全局最低点。

最后只记住这六句话#

  1. 文本进入模型前，要先变成向量。
  2. 模型内部的大部分计算，本质上是矩阵运算。
  3. 模型输出的是一组概率，不是凭空“想到”一个词。
  4. 损失函数负责衡量当前预测错得有多严重。
  5. 梯度告诉我们每个参数应该往哪个方向调整。
  6. 优化器根据梯度反复更新参数，这个过程就是训练。
