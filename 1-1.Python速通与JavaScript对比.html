二、变量与基本类型#

1. 动态类型#

Python 和 JavaScript 都是动态类型语言：变量的类型由运行时的值决定，同一个变量之后可以指向不同类型的值。

Python：

Python 
value = 10
value = "hello"

JavaScript：

JavaScript 
let value = 10;
value = "hello";

JavaScript 需要使用声明关键字：

  • const：变量绑定不会重新赋值，默认优先使用。
  • let：后续需要重新赋值时使用。
  • var：旧式声明，有函数作用域和变量提升等历史行为，现代代码通常不推荐。

2. 整数和浮点数#

Python：

Python 
age = 25          # int
price = 9.99      # float

JavaScript：

JavaScript 
const age = 25;       // number
const price = 9.99;   // number

关键区别：

  • Python 的 int 可以表示任意精度整数，float 通常是双精度浮点数。
  • JavaScript 的普通整数和小数通常都是 number，大整数可以使用 bigint，例如 123n。
  • JavaScript 的安全整数范围有限，可以通过 Number.isSafeInteger() 判断。

3. 字符串#

Python：

Python 
name = "小明"
print("Hi " + name)

JavaScript：

JavaScript 
const name = "小明";
console.log("Hi " + name);
console.log(`Hi ${name}`);

两门语言都支持字符串拼接和模板式插值：

Python JavaScript
f"Hi {name}" `Hi ${name}`

实战拆解："xxx%sxxx" % ("123")

这是 Python 的旧式字符串格式化语法。左边字符串中的 %s 是占位符，右边 % 后面的值会被填入该位置：

Python 
result = "xxx%sxxx" % ("123")
print(result)  # xxx123xxx

可以按下面三步理解：

  1. "xxx%sxxx" 是字符串模板。
  2. %s 表示“这里放入一个转换为字符串后的值”。
  3. % ("123") 把字符串 "123" 填到 %s 所在的位置。

这里的 ("123") 只是加了括号的普通字符串，不是元组；Python 的单元素元组必须带逗号，写成 ("123",)。

只有一个占位符时，括号通常可以省略：

Python 
"xxx%sxxx" % "123"  # "xxx123xxx"

有多个占位符时，需要把多个值放入元组，并按照位置依次替换：

Python 
"name=%s, age=%s" % ("小明", 18)
# "name=小明, age=18"

常见占位符包括：%s 表示字符串，%d 表示十进制整数，%f 表示浮点数；如果要输出百分号本身，需要写 %%。

现代 Python 通常更推荐可读性更好的 f-string：

Python 
value = "123"
result = f"xxx{value}xxx"  # "xxx123xxx"

JavaScript 中对应的是模板字符串：

JavaScript 
const value = "123";
const result = `xxx${value}xxx`; // "xxx123xxx"

一句话记忆："xxx%sxxx" % "123" = 用右侧的值替换左侧的 %s。

4. 布尔值与逻辑非#

Python：

Python 
is_rain = False
print(not is_rain)  # True

JavaScript：

JavaScript 
const isRain = false;
console.log(!isRain); // true

大小写不同：Python 使用 True、False，JavaScript 使用 true、false。

5. 类型转换#

Python：

Python 
num_str = "123"
num_int = int(num_str)
print(num_int + 7)   # 130
print(num_str + "7") # "1237"

JavaScript：

JavaScript 
const numStr = "123";
const numInt = Number(numStr);
console.log(numInt + 7);  // 130
console.log(numStr + 7);  // "1237"

关键区别：

  • Python 不允许直接执行 "123" + 7，会抛出 TypeError。
  • JavaScript 的 + 同时负责数值相加和字符串拼接，遇到字符串时可能发生隐式类型转换。
  • JavaScript 中建议显式使用 Number()、String()、Boolean()，减少隐式转换造成的问题。

常见转换对照：

目标 Python JavaScript
转整数 int(value) Number(value) 或 parseInt(value, 10)
转浮点数 float(value) Number(value) 或 parseFloat(value)
转字符串 str(value) String(value)
转布尔值 bool(value) Boolean(value)
查看类型 type(value) typeof value

注意：JavaScript 的 typeof null 是历史遗留的 "object"，不能据此判断 null。

三、基本运算符#

1. 算术运算#

假设：

Python 
a = 10
b = 4
JavaScript 
const a = 10;
const b = 4;
含义 Python JavaScript 结果
加法 a + b a + b 14
减法 a - b a - b 6
乘法 a * b a * b 40
普通除法 a / b a / b 2.5
取余/余数 a % b a % b 2
整除 a // b 无直接对应 2
幂运算 a ** b a ** b 10000

2. // 整除的差异#

Python 的 // 会向负无穷方向取整：

Python 
10 // 3    # 3
-11 // 3  # -4

JavaScript 没有 // 运算符。对于普通数值，可以使用：

JavaScript 
Math.floor(10 / 3);   // 3
Math.floor(-11 / 3); // -4

不要把 Math.trunc() 当作 Python // 的完整替代：

JavaScript 
Math.trunc(-11 / 3); // -3，向 0 截断
Math.floor(-11 / 3); // -4，向负无穷取整

3. 负数取余的差异#

这是 Python 和 JavaScript 中非常容易踩坑的一点。

Python：

Python 
-11 // 3  # -4
-11 % 3   # 1

Python 保证：

运行结果 / 结构 
a = (a // b) * b + (a % b)
-11 = (-4) * 3 + 1

当除数 b 为正数时，Python 的余数位于 0 <= 余数 < b。

JavaScript：

JavaScript 
-11 % 3; // -2

JavaScript 的 % 更接近“截断除法后的余数”，结果通常与被除数同号：

运行结果 / 结构 
-11 = (-3) * 3 + (-2)

因此：

表达式 Python JavaScript
-11 // 3 -4 无 //，Math.floor(-11 / 3) 为 -4
-11 % 3 1 -2

如果要在 JavaScript 中实现与 Python 一致的模运算，可以写：

JavaScript 
function pythonModulo(a, b) {
  return ((a % b) + b) % b;
}

pythonModulo(-11, 3); // 1

4. 比较运算#

Python：

Python 
a == c
a != c
a > c

JavaScript：

JavaScript 
a === c;
a !== c;
a > c;

关键区别：

  • Python 的 == 比较值，is 比较对象身份。
  • JavaScript 同时存在宽松相等 == 和严格相等 ===。
  • JavaScript 通常应优先使用 === 和 !==，避免隐式类型转换。

例如：

JavaScript 
"1" == 1;  // true，发生类型转换
"1" === 1; // false，类型不同

5. 逻辑运算#

含义 Python JavaScript
逻辑或 a or b `a
逻辑与 a and b a && b
逻辑非 not a !a

两门语言的“与”和“或”不一定返回布尔值，而是返回参与运算的某个值：

Python 
10 or 0   # 10
10 and 0  # 0
JavaScript 
10 || 0;  // 10
10 && 0;  // 0

但真假值规则存在重要差异：

值 Python JavaScript
空字符串 假 假
数字 0 假 假
None / null 假 假
空列表 [] 假 真
空字典/对象 {} 假 真

JavaScript 中数组和对象都是对象，即使为空也是真值。

四、数据结构#

4.1 列表与数组#

Python 的 list 对应 JavaScript 的 Array。二者都是可变、有序容器，并且都能存放不同类型的值。

创建、访问和修改#

Python：

Python 
scores = [85, 90, 78]
print(scores[1])
scores[1] = 95

JavaScript：

JavaScript 
const scores = [85, 90, 78];
console.log(scores[1]);
scores[1] = 95;

const 数组仍然可以修改内部元素；它只是不允许变量重新指向另一个数组。

添加与删除#

操作 Python JavaScript
尾部添加 scores.append(88) scores.push(88)
删除并返回尾元素 scores.pop() scores.pop()
删除并返回首元素 scores.pop(0) scores.shift()
首部添加 scores.insert(0, 88) scores.unshift(88)

负数索引#

Python 原生支持负数索引：

Python 
letters = ["a", "b", "c", "d", "e"]
letters[-1]  # "e"
letters[-2]  # "d"

JavaScript 的方括号不支持这种负数索引，应使用 at()：

JavaScript 
const letters = ["a", "b", "c", "d", "e"];
letters.at(-1); // "e"
letters.at(-2); // "d"

letters[-1] 在 JavaScript 中访问的是名为 "-1" 的对象属性，不是倒数第一个元素。

切片#

两门语言都采用左闭右开的区间：

Python 
letters[1:3]  # ["b", "c"]
JavaScript 
letters.slice(1, 3); // ["b", "c"]

列表推导式#

Python：

Python 
squares = [x ** 2 for x in range(5)]

JavaScript 没有列表推导式，通常使用 map()：

JavaScript 
const squares = Array.from({ length: 5 }, (_, x) => x ** 2);

带条件的 Python 列表推导式通常对应 JavaScript 的 filter() 和 map()：

Python 
squares = [x ** 2 for x in range(10) if x % 2 == 0]
JavaScript 
const squares = Array.from({ length: 10 }, (_, x) => x)
  .filter((x) => x % 2 === 0)
  .map((x) => x ** 2);

4.2 字典、普通对象与 Map#

Python 的 dict 是键值对容器。JavaScript 中要根据场景选择普通对象或 Map。

使用普通对象#

Python：

Python 
student = {
    "name": "李华",
    "age": 22,
    "courses": ["Math", "CS"]
}

print(student["name"])
print(student.get("gender", "未知"))

JavaScript：

JavaScript 
const student = {
  name: "李华",
  age: 22,
  courses: ["Math", "CS"],
};

console.log(student.name);
console.log(student.gender ?? "未知");

这里使用 ?? 而不是 ||，因为 ?? 只在左侧是 null 或 undefined 时使用默认值，不会把 0、false、空字符串误判为缺失。

实战拆解：**fused_item["best_item"]

在字典字面量 {...} 内，两个星号 ** 表示字典解包：取出目标字典中的所有键值对，并合并到正在创建的新字典中。它类似 JavaScript 对象中的展开语法 ...。

Python 
fused_item = {
    "best_item": {
        "id": 101,
        "text": "Python 字典解包",
        "original_score": 0.82,
    },
    "best_original_score": 0.95,
    "rrf_score": 0.032,
    "matched_queries": ["字典展开", "Python **"],
}

result = {
    **fused_item["best_item"],
    "original_score": fused_item["best_original_score"],
    "rrf_score": fused_item["rrf_score"],
    "matched_query_count": len(fused_item["matched_queries"]),
    "matched_queries": fused_item["matched_queries"],
}

执行顺序可以理解为：

  1. 先读取 fused_item["best_item"]，得到原始最佳结果字典。
  2. 通过 **，把它的 id、text、original_score 等字段复制到新字典 result。
  3. 再加入融合检索产生的 rrf_score、命中查询数量和查询列表。

同名键以后面的值为准。上例的 best_item 原本有 original_score: 0.82，但后面再次设置了 original_score，因此最终值是 0.95。

JavaScript 
const result = {
  ...fusedItem.bestItem,
  originalScore: fusedItem.bestOriginalScore,
  rrfScore: fusedItem.rrfScore,
  matchedQueryCount: fusedItem.matchedQueries.length,
  matchedQueries: fusedItem.matchedQueries,
};

需要注意：这里进行的是浅拷贝。顶层字典是新的，但其中嵌套的列表、字典等对象不会被递归复制。另外，fused_item["best_item"] 必须是字典或其他映射对象，否则这种字典解包会报错；其中的键需要是可哈希类型。

一句话记忆：**fused_item["best_item"] = 把最佳结果的全部字段铺进新字典。

新增、修改和删除#

Python：

Python 
student["gender"] = "female"
del student["age"]

JavaScript：

JavaScript 
student.gender = "female";
delete student.age;

遍历键值对#

Python：

Python 
for key, value in student.items():
    print(f"{key}: {value}")

JavaScript：

JavaScript 
for (const [key, value] of Object.entries(student)) {
  console.log(`${key}: ${value}`);
}

常用方法对照：

Python dict JavaScript 普通对象
student.keys() Object.keys(student)
student.values() Object.values(student)
student.items() Object.entries(student)
student.get(key, default) student[key] ?? default

什么时候使用 Map#

如果键不是固定字段名，或者需要频繁增加、删除和遍历键值对，JavaScript 的 Map 更接近 Python 的 dict：

JavaScript 
const student = new Map();
student.set("name", "李华");
student.set("age", 22);

console.log(student.get("name"));
console.log(student.has("gender"));
student.delete("age");

for (const [key, value] of student) {
  console.log(`${key}: ${value}`);
}

现代 Python 的字典会保持插入顺序。JavaScript 的 Map 也保持插入顺序；普通对象的属性顺序有更具体的规则，尤其是整数形式的键可能被重新排序。

4.3 元组#

Python 元组是有序、不可变的容器：

Python 
my_tuple = (1, 2, 3, "a")
print(my_tuple[0])
# my_tuple[0] = 5  # TypeError

JavaScript 没有与 Python 元组完全对应的通用内置类型。常见替代方式是数组：

JavaScript 
const tupleLike = [1, 2, 3, "a"];

如果希望运行时阻止修改，可以进行浅冻结：

JavaScript 
const tupleLike = Object.freeze([1, 2, 3, "a"]);

Object.freeze() 只做浅冻结；数组内部如果还有对象，嵌套对象仍可能被修改。

4.4 列表、元组和字符串转换#

容器连接为字符串#

Python：

Python 
letters = ["h", "e", "l", "l", "o"]
text = "-".join(letters)  # "h-e-l-l-o"

JavaScript：

JavaScript 
const letters = ["h", "e", "l", "l", "o"];
const text = letters.join("-"); // "h-e-l-l-o"

Python 的 join() 要求所有元素都是字符串：

Python 
"-".join([1, 2, 3])  # TypeError

JavaScript 会隐式执行字符串转换：

JavaScript 
[1, 2, 3].join("-"); // "1-2-3"

字符串拆成字符#

Python：

Python 
list("hello")  # ["h", "e", "l", "l", "o"]

JavaScript：

JavaScript 
Array.from("hello"); // ["h", "e", "l", "l", "o"]
[..."hello"];       // ["h", "e", "l", "l", "o"]

列表转元组#

Python：

Python 
tuple([1, 2, 3, "a"])  # (1, 2, 3, "a")

JavaScript 没有内置元组转换；可根据目的使用数组复制和冻结：

JavaScript 
const tupleLike = Object.freeze([...myList]);

按空白拆分字符串#

Python：

Python 
"i love china".split()  # ["i", "love", "china"]

JavaScript：

JavaScript 
"i love china".trim().split(/\s+/); // ["i", "love", "china"]

Python 的无参数 split() 会处理连续空白和换行；JavaScript 的 split(" ") 只按单个空格字符切割，语义并不完全相同。

五、条件判断#

Python：

Python 
age = 50

if age < 18:
    print("未成年")
elif age < 45:
    print("成年人")
elif 45 <= age < 65:
    print("45～64 岁")
else:
    print("65 岁及以上")

JavaScript：

JavaScript 
const age = 50;

if (age < 18) {
  console.log("未成年");
} else if (age < 45) {
  console.log("成年人");
} else if (age >= 45 && age < 65) {
  console.log("45～64 岁");
} else {
  console.log("65 岁及以上");
}

关键区别：

  • Python 使用缩进界定代码块，条件后有冒号。
  • JavaScript 使用花括号，条件通常放在圆括号中。
  • Python 使用 elif，JavaScript 使用 else if。
  • Python 支持 45 <= age < 65 这样的链式比较。
  • JavaScript 不能写成 45 <= age < 65，必须拆成 age >= 45 && age < 65。

JavaScript 中写 45 <= age < 65 会先得到布尔值，再把布尔值转换成数字继续比较，结果通常不符合业务意图。

六、循环#

6.1 for 循环#

Python 遍历列表：

Python 
for i in [0, 1, 2, 3, 4]:
    print(i ** 2)

JavaScript：

JavaScript 
for (const i of [0, 1, 2, 3, 4]) {
  console.log(i ** 2);
}

特别注意 JavaScript 的 for...of 与 for...in：

JavaScript 
for (const value of ["a", "b"]) {
  console.log(value); // "a"、"b"
}

for (const index in ["a", "b"]) {
  console.log(index); // "0"、"1"
}

遍历数组元素通常使用 for...of，不要误用 for...in。

实战拆解：enumerate(results[:5], 1)

这段表达式常用于“只展示前 5 条结果，并从 1 开始编号”。可以从内向外理解：

  • results[:5]：通过切片取出 results 的前 5 个元素；如果不足 5 个，就取实际存在的全部元素。
  • enumerate(..., 1)：遍历这些元素时，同时生成序号；第二个参数 1 表示序号从 1 开始，省略时默认从 0 开始。
  • 每轮会产生一个 (序号, 元素) 二元组，通常在 for 中直接解包为两个变量。
Python 
results = ["苹果", "香蕉", "橙子", "葡萄", "西瓜", "桃子"]

for index, result in enumerate(results[:5], 1):
    print(index, result)

# 1 苹果
# 2 香蕉
# 3 橙子
# 4 葡萄
# 5 西瓜

其中 index, result 是元组解包：例如 (1, "苹果") 会被分别赋值给 index 和 result。

对应的 JavaScript 写法可以使用 slice(0, 5) 配合数组下标：

JavaScript 
const results = ["苹果", "香蕉", "橙子", "葡萄", "西瓜", "桃子"];

results.slice(0, 5).forEach((result, index) => {
  console.log(index + 1, result);
});

一句话记忆：enumerate(results[:5], 1) = 前 5 条 + 从 1 编号。

6.2 range#

Python：

Python 
for i in range(2, 10, 3):
    print(i)  # 2、5、8

range(start, stop, step) 采用左闭右开区间，不包含 stop。

JavaScript 没有内置 range()，通常写普通循环：

JavaScript 
for (let i = 2; i < 10; i += 3) {
  console.log(i); // 2、5、8
}

6.3 while、continue 和自增#

Python：

Python 
count = 0

while count < 5:
    print(count)
    count += 0.5
    if count > 4:
        continue
    print(count)

JavaScript：

JavaScript 
let count = 0;

while (count < 5) {
  console.log(count);
  count += 0.5;
  if (count > 4) {
    continue;
  }
  console.log(count);
}

continue 会跳过本轮循环剩余代码，直接进入下一轮。两门语言都支持 break 立即结束循环。

JavaScript 还支持 count++，但它只能增加 1；Python 没有 ++ 运算符。

七、函数#

1. 定义与调用#

Python：

Python 
def greet(name, greeting="你好"):
    return f"{greeting}, {name}!"

print(greet("Alice"))
print(greet("Bob", "Hello"))

JavaScript：

JavaScript 
function greet(name, greeting = "你好") {
  return `${greeting}, ${name}!`;
}

console.log(greet("Alice"));
console.log(greet("Bob", "Hello"));

也可以使用箭头函数：

JavaScript 
const greet = (name, greeting = "你好") => `${greeting}, ${name}!`;

2. 默认参数#

两门语言都支持默认参数，但细节不同：

JavaScript 
greet("Alice", undefined); // 使用默认值
greet("Alice", null);      // greeting 为 null，不使用默认值

Python 需要额外注意：不要把可变对象直接作为默认参数，否则它会在多次调用之间复用。

Python 
# 不推荐
def add_item(item, items=[]):
    items.append(item)
    return items

应改为：

Python 
def add_item(item, items=None):
    if items is None:
        items = []
    items.append(item)
    return items

3. 返回多个值与解构#

Python 实际返回一个元组：

Python 
def calculate(a, b):
    return a + b, a * b

sum_result, product_result = calculate(5, 4)
# 9、20

JavaScript 可以返回数组并解构：

JavaScript 
function calculate(a, b) {
  return [a + b, a * b];
}

const [sumResult, productResult] = calculate(5, 4);

当返回值含义较多时，JavaScript 更适合返回对象：

JavaScript 
function calculate(a, b) {
  return {
    sum: a + b,
    product: a * b,
  };
}

const { sum, product } = calculate(5, 4);

Python 也支持返回字典或自定义对象，避免调用者依赖位置记忆含义。

八、文件操作#

8.1 Python 文件写入与读取#

Python 
with open("diary.txt", "w", encoding="utf-8") as file:
    file.write("2023-10-01\n")
    file.write("今天学习了Python\n")

with open("diary.txt", "r", encoding="utf-8") as file:
    lines = file.readlines()
    for line in lines:
        print(line.strip())

重点：

  • "w" 表示覆盖写入。
  • "r" 表示读取。
  • \n 表示换行。
  • encoding="utf-8" 明确文本编码。
  • with 代码块结束后会自动关闭文件。
  • strip() 会移除字符串首尾空白，包括换行符。

8.2 Node.js 对应写法#

同步写法：

JavaScript 
import fs from "node:fs";

fs.writeFileSync(
  "diary.txt",
  "2023-10-01\n今天学习了JavaScript\n",
  "utf8",
);

const content = fs.readFileSync("diary.txt", "utf8");
const lines = content.split(/\r?\n/);

for (const line of lines) {
  console.log(line.trim());
}

异步写法：

JavaScript 
import fs from "node:fs/promises";

await fs.writeFile(
  "diary.txt",
  "2023-10-01\n今天学习了JavaScript\n",
  "utf8",
);

const content = await fs.readFile("diary.txt", "utf8");

关键区别：

  • Python 提供内置 open()；JavaScript 需要引入 Node.js 的 fs 模块。
  • Node.js 服务端代码更常用 Promise 版本的异步文件 API，避免同步 I/O 阻塞事件循环。
  • 浏览器 JavaScript 受到安全沙箱限制，不能像 Node.js 一样通过路径任意读写用户文件。
  • 相对路径都基于程序运行时的当前工作目录，不一定是源代码文件所在目录。

九、异常处理#

Python：

Python 
try:
    x = 10 / 0
except ZeroDivisionError:
    x = 1
    print("除数不能为零！")

JavaScript：

JavaScript 
try {
  const x = riskyOperation();
} catch (error) {
  console.error(error);
}

关键差异：JavaScript 的普通数字除以零不会抛出异常：

JavaScript 
10 / 0; // Infinity
0 / 0;  // NaN

所以不能通过 try...catch 捕获 JavaScript 普通数字的除零行为，应主动校验：

JavaScript 
function divide(a, b) {
  if (b === 0) {
    throw new RangeError("除数不能为零");
  }
  return a / b;
}

try {
  console.log(divide(10, 0));
} catch (error) {
  if (error instanceof RangeError) {
    console.error(error.message);
  } else {
    throw error;
  }
}

对照：

Python JavaScript
try try
except catch
raise throw
finally finally
ZeroDivisionError 普通数字除零不抛异常
FileNotFoundError Node.js 常见错误码 ENOENT

捕获异常时应尽量处理具体错误，不要无条件吞掉所有异常。

十、类与对象#

1. Python#

Python 
class Dog:
    def __init__(self, name, age, color):

        self.age = age
        self.color = color

  }

对照：

概念 Python JavaScript

构造方法 __init__ constructor

创建实例 Dog(...) new Dog(...)

JavaScript 的 this 由函数如何被调用决定。把对象方法单独传递给其他函数时，可能丢失原来的 this：

JavaScript 
const bark = dog1.bark;
bark(); // this 可能是 undefined

十一、综合案例：单词频率统计#

这个案例综合使用了：

  • 函数定义和返回值
  • 文件读取
  • 异常处理
  • 字符串转小写
  • 字符串切分
  • 列表遍历
  • 字典读取、更新和默认值

1. Notebook 中的 Python 实现思路#

Python 
def count_words(filename):
    try:
        with open(filename, "r", encoding="utf-8") as file:
            content = file.read().lower()
            words = content.split()

        word_count = {}
        for word in words:
            word_count[word] = word_count.get(word, 0) + 1

        return word_count
    except FileNotFoundError:
        print("文件不存在！")
        return {}

执行过程：

运行结果 / 结构 
文件路径
  → 读取全文
  → 转为小写
  → 按空白切词
  → 遍历单词
  → 使用字典累计频率
  → 返回统计结果

word_count.get(word, 0) 表示：如果单词已存在就取得原计数，否则使用 0，然后加 1。

2. JavaScript 的 Node.js 实现#

使用普通对象：

JavaScript 
import fs from "node:fs/promises";

async function countWords(filename) {
  try {
    const content = (await fs.readFile(filename, "utf8")).toLowerCase();
    const words = content.trim().split(/\s+/);
    const wordCount = Object.create(null);

    for (const word of words) {
      wordCount[word] = (wordCount[word] ?? 0) + 1;
    }

    return wordCount;
  } catch (error) {
    if (error?.code === "ENOENT") {
      console.error("文件不存在！");
      return Object.create(null);
    }
    throw error;
  }
}

const result = await countWords("综合案例文本.txt");
console.log("单词频率:", result);

使用 Map：

JavaScript 
const wordCount = new Map();

for (const word of words) {
  wordCount.set(word, (wordCount.get(word) ?? 0) + 1);
}

Map 版本与 Python 的 dict.get() 思路更接近。

3. 原案例的文本清洗限制#

原案例只按空白切分，不会去除标点。因此下面这些内容会被统计成不同单词：

运行结果 / 结构 
dog
dog,
dog.
dog!

更合理的简单 Python 版本可以先用正则提取单词：

Python 
import re

words = re.findall(r"[a-z]+(?:[-_][a-z]+)*", content.lower())

JavaScript 对应写法：

JavaScript 
const words = content.toLowerCase().match(/[a-z]+(?:[-_][a-z]+)*/g) ?? [];

“如何定义单词”取决于业务：连字符、下划线、数字、中文和 Unicode 字符是否算单词，都需要明确规则。

十二、原 Notebook 中需要修正的内容#

下面是阅读原 Notebook 时需要注意的错误或不严谨表述。

1. 字符串拼接结果错误#

原注释把下面结果写成了 130：

Python 
num_str = "123"
num_str + "7"

实际结果是字符串 "1237"。只有先转换成整数再加 7 才会得到 130。

2. 运算示例的注释沿用了旧变量#

代码使用 a = 10、b = 4，部分注释却仍按 b = 3 描述。实际结果应以当前代码为准：

运行结果 / 结构 
a + b  = 14
a - b  = 6
a * b  = 40
a / b  = 2.5
a % b  = 2
a // b = 2
a ** b = 10000

3. pop() 的说明错误#

Python 
scores.pop()

它删除的是最后一个元素，不是第一个元素。删除第一个元素应使用 scores.pop(0)。

4. 负数索引说明错误#

Python 
letters = ["a", "b", "c", "d", "e"]
letters[-2]

结果是 "d"，letters[-1] 才是 "e"。

5. 字典“无序”的说法已经不准确#

现代 Python 的 dict 会保持插入顺序，但仍应通过键访问数据，不要把字典当作列表使用。

6. “元祖”应为“元组”#

正确术语是“元组（tuple）”。

7. join() 的输出注释错误#

Python 
"-".join(["h", "e", "l", "l", "o"])

结果是 "h-e-l-l-o"，不是 "hello"。

8. range() 的步长注释错误#

Python 
range(2, 10, 3)

步长是 3，结果是 2、5、8，不是步长 2。

9. 函数返回值注释错误#

Python 
calculate(5, 4)

和与积是 9、20，不是 7、12。

10. 当前类示例无法执行#

原代码存在两个问题：

Python 
self.color = coler       # coler 拼写错误
dog1 = Dog("Buddy", 3)  # 少传 color 参数

应改为：

Python 
self.color = color
dog1 = Dog("Buddy", 3, "brown")

Notebook 中保存的 Buddy says woof! 输出很可能来自代码被修改之前的某次执行，并不代表当前单元格可以重新运行成功。

11. 综合案例应明确编码#

读取文本时建议写出：

Python

避免运行环境默认编码不同导致中文文件读取失败。

十三、从 JavaScript 转学 Python 的重点#

如果已经熟悉 JavaScript，学习这份 Python 速通内容时应优先建立以下对应关系：

  1. const、let 不再出现，Python 变量直接赋值。
  2. {} 代码块变成缩进，缩进属于语法的一部分。
  3. === 变成 ==，对象身份比较使用 is。
  4. &&、||、! 变成 and、or、not。
  5. Array 变成 list，push() 变成 append()。
  6. Object 或 Map 对应 dict。
  7. for...of 大致对应 Python 的 for...in；Python 会依次取得可迭代对象产生的元素，遍历字典时默认取得键，不要套用 JavaScript for...in 的含义。
  8. Python 支持负数索引、切片、列表推导式和链式比较。
  9. Python 有 //，而且 Python 与 JavaScript 的负数 % 结果可能不同。
  10. Python 的空列表、空字典是假值，JavaScript 的空数组、空对象是真值。
  11. def 对应 function，Python 多返回值实际是元组。
  12. with open() 对应 Node.js fs，但 Node.js 更常使用异步 I/O。
  13. except 对应 catch，但 JavaScript 普通数字除以零不会抛异常。
  14. self 对应 this，Python 创建实例不使用 new。

掌握这些差异后，就可以把已有的 JavaScript 编程思维迁移到 Python，并继续学习模型 API 调用、JSON 处理、第三方包、异步请求和大模型应用开发。
